این قسمت پایانی سری کامپوننت‌های سرور React است. یاد می‌گیریم چگونه به طور مؤثر کامپوننت‌های سرور و کلاینت را ترکیب کنیم.

## دایرکتیو "use client"

برای ایجاد یک کامپوننت کلاینت، دایرکتیو `'use client'` را در بالای فایل اضافه کنید:

```typescript
'use client';

import { useState } from 'react';

export function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(c => c + 1)}>{count}</button>;
}
```

## الگوهای ترکیب (Composition)

کامپوننت‌های سرور می‌توانند کامپوننت‌های کلاینت را ایمپورت و رندر کنند، اما برعکس ممکن نیست. این یک مرز طبیعی ایجاد می‌کند.
