کامپوننت‌های سرور React (RSC) نماینده یک تغییر پارادایم در نحوه ساخت اپلیکیشن‌های React هستند. در این قسمت اول از سری، مفاهیم پایه RSC و اهمیت آن‌ها را کاوش می‌کنیم.

## کامپوننت‌های سرور React چیست‌اند؟

کامپوننت‌های سرور React به شما امکان می‌دهند کامپوننت‌ها را فقط در سمت سرور رندر کنید و باندل JavaScript ارسالی به کلاینت را کاهش دهید. این بدان معناست:

- **صفر جاوااسکریپت سمت کلاینت** برای کامپوننت‌های سرور-فقط
- **دسترسی مستقیم پایگاه داده** بدون نیاز به API routes
- **تقسیم خودکار کد** در سطح کامپوننت

## مزایای کلیدی

کامپوننت‌های سرور می‌توانند عملکرد را به طور قابل توجهی بهبود بخشند و وابستگی‌های بزرگ را در سرور نگه دارند. کاربران شما جاوااسکریپت کمتری دانلود می‌کنند و اپ شما سریع‌تر به نظر می‌رسد.

## نگاه به جلو

در قسمت بعد، به طور عمیق‌تر به **الگوهای واکشی داده** با RSC و نحوه ترکیب آن‌ها با کامپوننت‌های کلاینت برای تجربیات تعاملی می‌پردازیم.
