به راهنمای سفارشی‌سازی پیشرفته Zahit خوش آمدید! از آنجا که Zahit تحت زیبایی‌شناسی مینیمالیستی خالص طراحی شده، کدبیس خام، شفاف و بسیار آسان برای تغییر است. در این آموزش، نحوه به‌روزرسانی کارت پروفایل بیوگرافی، تنظیم ویژگی‌های کلیدی CSS در سیستم طراحی سراسری و سفارشی‌سازی دیکشنری ترجمه را نشان می‌دهیم.

---

## 👤 ۱. ویرایش متادیتای اصلی: `src/config.ts`

برای شخصی‌سازی نام، نقش فعلی، بیوگرافی کوتاه و لینک‌های اجتماعی خود، فایل `src/config.ts` را باز کنید. این فایل سه پیکربندی اصلی صادر می‌کند:

### SITE_CONFIG
پارامترهای سراسری وب‌سایت شما را تعریف می‌کند:
- `title`: در زبانه‌های مرورگر و هدرهای چیدمان صفحه نمایش داده می‌شود.
- `description`: برای توضیحات پیش‌فرض متادیتای سئو استفاده می‌شود.
- `url`: آدرس دامنه ریشه کانونیکال که وبلاگ شما در آن مستقر شده است.

### AUTHOR
داده‌های کارت پروفایل شما را نگهداری می‌کند:
- `name`: نام کامل شما.
- `role`: نقش‌های محلی‌سازی‌شده برای فارسی (`fa`) و انگلیسی (`en`).
- `bio`: خلاصه‌های کوتاه محلی‌سازی‌شده که زیر تصویر آواتار شما رندر می‌شوند.
- `avatar`: مسیر عکس پروفایل شما (در `/public/` قرار داده شده، مثلاً `/profile.jpeg`).

### SOCIALS
فهرستی از حساب‌های اجتماعی که به‌صورت آیکون‌های گرد شناور در سایدبار دسکتاپ یا فوتر موبایل رندر می‌شوند:
```typescript
export const SOCIALS = [
  {
    label: 'GitHub',
    href: 'https://github.com/aryan',
    icon: 'mdi:github',
  },
  // لینک‌های بیشتر را با همان ساختار طرح‌واره اضافه کنید
];
```
*نکته: هر پیشوند کد Iconify (مانند `mdi:`) می‌تواند برای رندر خودکار SVG سفارشی ارجاع داده شود.*

## 🎨 ۲. سفارشی‌سازی طرح‌واره و رنگ‌بندی

طراحی Zahit کاملاً توسط متغیرهای CSS در `src/styles/global.css` کنترل می‌شود. می‌توانید کل رنگ‌بندی و تایپوگرافی قالب را با ویرایش مقادیر تعریف‌شده در شبه‌انتخابگر `:root` تغییر دهید:

```css
:root {
  /* رنگ‌های اصلی */
  --bg-color: #00022b;     /* رنگ پس‌زمینه بوم عمیق */
  --dark: #010e54;         /* پنل‌های تأکیدی و پس‌زمینه کانتینرها */
  --accent: #0855b1;       /* متن لینک اصلی، حاشیه‌ها و دکمه‌ها */
  --light: #4fa5d8;        /* افکت‌های hover، عناوین پویا و نشانه‌های روشن */
  --text-color: #daeaff;   /* سایه ملایم برای خوانایی متن */

  /* تایپوگرافی */
  --font-family-body: 'Source Sans 3', 'Vazirmatn', sans-serif;
  --font-family-heading: 'Source Sans 3', 'Vazirmatn', sans-serif;

  /* عرض چیدمان */
  --site-width: 80%;
  --content-padding: 2rem;
}
```

### ایجاد طرح‌واره سبز جنگلی:
برای مثال، برای تغییر قالب از حالت آبی فضایی به طرح جنگلی تاریک، متغیرهای رنگ را عوض کنید:
```css
:root {
  --bg-color: #0d1a0d;
  --dark: #1b331b;
  --accent: #2e662e;
  --light: #66cc66;
  --text-color: #e2f2e2;
}
```

## 🗣️ ۳. تغییر ترجمه‌های دیکشنری: `src/i18n/ui.ts`

تمام قطعات متن استاتیک مربوط به رابط کاربری (مانند ناوبری، متن «منتشر شده در» یا عنوان سایدبار «فهرست مطالب») در فایل `src/i18n/ui.ts` ذخیره شده‌اند.

برای افزودن یا تغییر رشته‌های ترجمه، به شیء `ui` نگاه کنید:

```typescript
export const ui = {
  fa: {
    'nav.home': 'خانه',
    'toc.title': 'فهرست مطالب',
  },
  en: {
    'nav.home': 'Home',
    'toc.title': 'Contents',
  },
} as const;
```

به‌سادگی مقادیر رشته مربوطه را به‌روز کنید یا کلیدهای جدیدی اضافه کنید تا دیکشنری را طبق نیاز خود تطبیق دهید.
