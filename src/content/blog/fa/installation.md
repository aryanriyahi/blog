به راهنمای نصب این وبلاگ خوش آمدید! این وبلاگ یک سایت مینیمال و ساده Astro v7 است که بر اساس فلسفه‌ای ساخته شده که سادگی، عمق است. در این راهنما، فرآیند کلون کردن مخزن، نصب وابستگی‌های مورد نیاز و راه‌اندازی محیط توسعه محلی را بررسی می‌کنیم.

## پیش‌نیازها

قبل از شروع، مطمئن شوید پیش‌نیازهای زیر روی سیستم شما نصب است:

- **Node.js:** نسخه `22.12.0` یا بالاتر توصیه می‌شود. می‌توانید نسخه خود را با اجرای دستور زیر بررسی کنید:
  ```bash
  node --version
  ```
- **Git:** برای کلون کردن مخزن و مدیریت نسخه‌های کد منبع ضروری است.

---

## گام ۱: کلون کردن مخزن

برای نصب وبلاگ، ابتدا باید مخزن را در دایرکتوری محلی خود کلون کنید. ترمینال خود را باز کرده و دستور زیر را اجرا کنید:

```bash
git clone https://github.com/aryanriyahi/blog.git
```

پس از تکمیل فرآیند کلون، وارد دایرکتوری پروژه شوید:

```bash
cd blog
```

---

## گام ۲: نصب وابستگی‌های پروژه

این وبلاگ از وابستگی‌های سبکی مانند `@astrojs/mdx` برای رندر محتوا و `astro-icon` برای آیکون‌های SVG استفاده می‌کند. دستور زیر را در پوشه ریشه پروژه اجرا کنید تا همه پکیج‌های مورد نیاز نصب شوند:

```bash
npm install
```

این دستور فایل `package.json` را می‌خواند و پوشه محلی `node_modules` را ایجاد می‌کند.

---

## گام ۳: اجرای سرور توسعه

اکنون که نصب تکمیل شده، می‌توانید سرور توسعه سریع Astro را راه‌اندازی کنید:

```bash
npm run dev
```

ترمینال شما URL محلی فعال را نمایش می‌دهد که معمولاً به این شکل است:

```text
  ┃ Local    http://localhost:4321/
```

مرورگر دلخواه خود را باز کرده و به `http://localhost:4321/` بروید تا محیط مینیمال و زنده خود را مشاهده کنید! هر تغییری در کد منبع به‌صورت بلادرنگ به‌روزرسانی می‌شود.
