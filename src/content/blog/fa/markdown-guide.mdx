مارک‌داون یک زبان نشانه‌گذاری سبک است که به شما اجازه می‌دهد با استفاده از متن ساده، اسناد قالب‌بندی‌شده ایجاد کنید. این طبیعی‌ترین راه برای تولید محتوا در سایت‌های مبتنی بر Astro مانند این وبلاگ است.

## عنوان‌ها

```
# عنوان H1
## عنوان H2
### عنوان H3
```

## قالب‌بندی متن

برای **متن پررنگ** از دو ستاره، برای *کج* از یک ستاره و برای ~~خط‌خورده~~ از دو مداده استفاده کنید.

> برای بلوک‌های نقل‌قول از `>` استفاده کنید. این راهی عالی برای برجسته کردن جملات مهمی است که می‌خواهید خواننده توجه کند.

## فهرست‌ها

فهرست نامرتب:
- اولین مورد
- دومین مورد
  - مورد تو در تو
- سومین مورد

فهرست مرتب:
1. اول این را انجام دهید
2. سپس این را
3. در نهایت این را

## لینک‌ها و تصاویر

لینک‌ها را با قالب [سایت رسمی Astro](https://astro.build) اضافه کنید.

## بلوک‌های کد

برای `کد` درون‌خطی از بک‌تیک استفاده کنید.

```javascript
function tagline() {
  return 'سادگی، عمق است، نه کمبود.';
}
```

## جدول‌ها

| سینتکس | توضیح |
|--------|----------|
| `**پررنگ**` | متن پررنگ |
| `*کج*` | متن کج |
| `[متن](url)` | لینک |

یادگیری مارک‌داون چند دقیقه طول می‌کشد؛ اما درک آن به یک مهارت مادام‌العمر تبدیل می‌شود.
