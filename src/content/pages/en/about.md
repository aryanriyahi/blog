# About

Welcome! I'm Aryan, a software developer interested in modern web technologies and open source projects. This is my personal blog where I document projects, share thoughts, and write about things I find worth sharing.

## About This Blog

This blog is built with [Astro](https://astro.build) using the [Zahit](https://github.com/kuscadev/Zahit) theme — a raw, flat minimalist theme built on the philosophy that simplicity is depth. It supports bilingual content in Persian (Farsi) and English, with full right-to-left layout support for Persian.

## Features

- Clean, minimalist design
- Bilingual support (Persian & English)
- Right-to-left layout for Persian
- Markdown and MDX support
- Code syntax highlighting
- Tags and categorization
- SEO-friendly structure
- RSS feeds per language
